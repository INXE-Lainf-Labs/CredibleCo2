# CredibleCO2

CredibleCO2 is a machine-learning framework for comparing vehicle-powertrain emissions while conditioning on the shared operating covariates that are actually observed. The current revision does **not** claim that identical speed alone establishes identical operating conditions, nor that a final causal EV-ICEV comparison has already been executed.

## Canonical reproducibility path

The revised manuscript results were generated with the leakage-free complete-trip protocol implemented in [`src/revision_protocol.py`](src/revision_protocol.py) and the revision runners under [`scripts/`](scripts/).

The protocol is:

1. Split complete trip IDs into train, validation, and test sets before preprocessing.
2. Fit each `MinMaxScaler` only on rows belonging to the training trips.
3. Apply that fitted scaler, without refitting, to validation and test trips. Values outside `[0, 1]` are possible and expected when a held-out trip exceeds the training range.
4. Create length-10 sliding windows independently inside each trip and split, so no window crosses a trip or partition boundary.
5. Select hyperparameters and LSTM checkpoints using validation trips only.
6. Evaluate the selected model once on the held-out test trips.

Primary implementation files:

- [`src/revision_protocol.py`](src/revision_protocol.py): deterministic complete-trip split, training-only scaling, trip-local windows, metrics, and bootstrap utilities.
- [`scripts/run_revision_lstm_cpu.py`](scripts/run_revision_lstm_cpu.py): corrected LSTM training and validation-selected checkpoint restoration.
- [`scripts/run_revision_experiments.py`](scripts/run_revision_experiments.py): corrected benchmark and ablation experiments.
- [`scripts/run_revision_full_data_head_to_head.py`](scripts/run_revision_full_data_head_to_head.py): full-data LSTM-versus-baseline comparisons.
- [`.github/workflows/`](.github/workflows/): auditable GitHub Actions workflows used for the revision runs.
- [`artifacts/`](artifacts/): split manifests, metrics, checkpoints, summaries, and audit outputs generated by the corrected protocol.

The exact deterministic split seed used for the revised experiments is `20260801`. The emissions-model robustness study uses training seeds `20260801` through `20260805` while holding the trip split fixed.

## Important legacy-code notice

The original notebooks [`src/LSTM_EV.ipynb`](src/LSTM_EV.ipynb), [`src/LSTM_ICEV.ipynb`](src/LSTM_ICEV.ipynb), and the historical functions in [`src/helper.py`](src/helper.py) are retained for provenance only. They represent the pre-revision workflow and **must not be used to reproduce the revised manuscript results**.

In particular, the historical workflow fitted `MinMaxScaler` before the trip split and created the inner train/validation split after concatenating overlapping windows. Those operations can leak held-out distribution information and adjacent timesteps across partitions. See [`src/README.md`](src/README.md) for the legacy/canonical distinction.

## Scope and limitations

The repository supports domain-specific emissions models, an EV context-to-actuation feature model, empirical evaluation of proxy-composition error, trip-level bootstrap uncertainty, and sensitivity analyses. A final route-matched EV-ICEV comparison still requires paired-route data and measured or controlled grade, payload, wind, driver protocol, and richer ICEV powertrain state. The current results should therefore be interpreted as predictive component evaluation and readiness assessment, not as a causal powertrain-effect estimate.
